# Communes de France

Application web pour chercher une commune française, la garder en favori et consulter sa fiche : département, région, population, surface et codes postaux.

**Site en ligne :** https://web-five-omega-wwh7cw4a7o.vercel.app/

## Technologies

React, TypeScript, Vite et React Router. Les données viennent de l'[API Géo](https://geo.api.gouv.fr).

## Contenu du dépôt

- `communes-ts` : l'application mise en ligne, écrite en TypeScript ;
- `communes` : la même application en JavaScript ;
- `seance1` : mes premiers composants React.

## Lancer l'application sur son poste

Dans le dossier `communes-ts`, taper `npm install`, puis `npm run dev`.
